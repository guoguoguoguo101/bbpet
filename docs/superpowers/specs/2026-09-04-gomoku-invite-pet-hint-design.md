# 五子棋邀请：桌宠提示

被邀请方只盯着桌宠、好友面板和学校都没开时，也能看出有人邀下棋，并点宠物去接受。

## 背景

`docs/superpowers/specs/2026-09-04-gomoku-design.md` 把邀请条放在好友面板和学校顶栏，并写明不做桌面气泡。结果是：两个面板都关着时，邀请会静默 60 秒过期。

这一刀只补被邀请方桌宠上的提示。校长协议、棋盘窗、邀请入口不变。

## 目标

收到 `pending` 且自己是白方的邀请时，桌宠头上漂字；若当时在发呆或眨眼，改成探头冒汗。左键轻点打开好友面板，在原有邀请条上接受或拒绝。

成功标准：

- 空桌收到邀请：探头 + 「有人邀你下棋」。
- 轻点（未拖动）打开好友面板，不再打开「今天去哪」。
- 睡觉、聚会、演示时姿势不变，只漂字。
- 邀请结束（接受、拒绝、过期、断线）后字消失；若当时是邀请探头，回到发呆。

## 规则

- 只有被邀请方显示。邀请方桌宠不改。
- 文案固定：`有人邀你下棋`。不含对方名字、不含倒计时。
- 接受 / 拒绝仍只在好友面板（或已打开的学校顶栏），不做到宠物身上。
- 探头只给本机桌宠看，不同步到学校地图或别人家里。

姿势：

| 当前状态 | 姿势 | 漂字 |
| --- | --- | --- |
| 发呆 `idle`、眨眼 `blink` | 改为 `peek` | 是 |
| 睡觉、醒来、喝水、打字、摸鱼（电话/零食/游戏机/`peek` 等）、聊天说话 | 保持 | 是 |
| 在家聚会 `gathering` | 保持 | 是（只加在自己那只上） |
| 演示姿势 `demoing` | 保持 | 是 |

邀请到来时若在睡觉等非发呆姿势：只漂字。之后一旦回到发呆且邀请仍在，再改成探头。

邀请探头期间：暂停眨眼、午睡、摸鱼循环，避免把探头盖掉。聚会和演示不走这条锁定。

## 架构

不改 WebSocket，不新开窗口。宠物窗已经能收到 `RoomView.game`。

```
校长 gameState
        │
桌宠主进程 roomClient
        │ room-state
        ▼
PetApp ── isIncomingInvite ──► 漂字 + 条件探头
        │
        └ 轻点 ──► openPanel('friends')
```

## 组件

| 单元 | 职责 | 依赖 |
| --- | --- | --- |
| `invitePetPose`（纯函数，与 `isIncomingInvite` 同层或紧挨着） | 给定当前姿势和是否聚会/演示，返回 `peek` 或「保持」 | `PetPose` |
| `PetApp` | 漂字、条件探头、暂停日常循环、轻点改开好友面板 | `isIncomingInvite`、`invitePetPose` |
| `Gathering` | 聚会时在自己槽位头上漂同一句 | 父组件传入「正在被邀请」 |
| 窗口形状 | 沿用 `.pet-emote`，点击穿透到宠物 | 现有 `collectPetShape` / `hitTest` |

好友面板邀请条、学校顶栏、棋盘窗、校长对局表都不改。

## 界面

- 漂字用现成 `.pet-emote`（描边小框、轻微浮动）。`pointer-events: none`，点在字上等于点宠物。
- 探头沿用现有 `peek` 帧（冒汗 + 左右张望）。
- 左键轻点：未拖动（位移阈值仍是现有的约 6px）且点在宠物实体上 → `openPanel('friends')`。好友面板已开则聚焦。拖动、右键菜单不变。
- 聚会时点**自己**这只（未拖动）同样打开好友面板。点别人仍是右键动作菜单。

## 数据流

1. `gameState` 写入 `RoomView.game`。
2. `isIncomingInvite(game)` 为真 → 显示漂字。
3. `invitePetPose` 若返回 `peek`，且不在聚会/演示 → `setPose('peek')`，并跳过日常 idle 循环。
4. 邀请不再 pending（接受变成 `playing`、拒绝/过期 `ended`、`game` 为 `null`）→ 去掉漂字；**仅当这次邀请把 `idle`/`blink` 改成了 `peek`（邀请锁）时**才设回 `idle` 并恢复循环。摸鱼循环里碰巧已经是 `peek` 的，不算邀请锁，邀请结束不强制改姿势。

`welcome` 带回 pending 邀请时，行为与当场收到 `gameState` 相同。

## 错误处理

| 情况 | 行为 |
| --- | --- |
| 接受 / 拒绝 / 60 秒过期 / 邀请方断开导致局作废 | 漂字消失；邀请探头回到发呆 |
| 连校长失败、`game` 为 `null` | 不当成还在被邀请 |
| 好友面板已经开着 | 轻点只聚焦，不另开第二块 |
| 演示进行中 | 不改演示姿势；演示结束若邀请还在且已发呆，再探头 |
| 打开棋盘窗（已接受） | 提示结束，姿势恢复日常循环 |
| 点在漂字上 | 落到宠物身上，轻点仍开好友面板 |

不在宠物上发送 `gameRespond`，点错不会误接受或误拒绝。

## 测试

`invitePetPose`：

- `idle` / `blink` → `peek`
- `sleep` / `drink` / `type` / `phone` / `peek` 等 → 保持
- `gathering` 或 `demoing` 为真 → 无论当前姿势都保持

接到现有 `shared/gameView.test.ts`（或同目录新文件，由测试脚本一并跑）。

手动：

- 空桌收到邀请：探头 + 字；轻点打开好友面板顶部邀请条
- 睡觉时收到：只漂字，仍在睡
- 接受或过期后：字消失，恢复发呆

## 明确不做

- 自动弹出好友面板
- 宠物上的接受 / 拒绝按钮
- 邀请方桌宠动画
- 把探头同步到学校或别人家里
- 独立桌面气泡窗
- 改文案带名字或倒计时
- 改校长协议或棋盘窗
