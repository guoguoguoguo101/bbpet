# BbPet v2：学校 / 家 / 好友互动（规划）

原先叫「复古像素会议室」。范围已扩成三块社交：去上学、回家串门、好友动作与小游戏。v1 桌宠、天气新闻、LLM 对话保持单机，不把 Key 和私聊同步到服务器。

配套交互稿：[bbpet-v2-social.canvas.tsx](C:/Users/guohongzhi/.cursor/projects/d-idea-project-bbpet/canvases/bbpet-v2-social.canvas.tsx)

## 和 v1 的关系

当前左键直接 `openPanel('chat')`，面板只有 LLM。v2 **不要**把学校塞进这个小对话框。

| v1 保留 | v2 新增 |
| --- | --- |
| 透明置顶宠物、右键天气/新闻/设置 | 左键改为社交枢纽 |
| LLM 对话（枢纽里一项） | 独立 800×600 像素世界窗 |
| 本地 `pet` 形象 | 内网 WebSocket 房主 |

同一时刻只在一个地方：桌面 / 学校某房间 / 某个人的家 / 一局游戏。

## 交互主轴

### 左键枢纽（所有入口的分发点）

点宠物先看到自己的形象和四个入口：

1. **和宠物聊** — 现有 LLM 面板，完全单机
2. **去上学** — 打开世界窗，出生在校门口
3. **回家** — 打开世界窗，进入 `home:{自己}`
4. **好友** — 在线列表，可邀请串门或开局

桌宠继续当通知铃：人不在世界窗时，串门/对局邀请冒在宠物气泡上，60 秒未点过期。

### 学校（公共）

- 俯视像素校园：三个班级 + 活动室，走廊 WASD 走动，撞墙停下。
- 走进门切场景，出生点在门口。
- **黑板聊天 = 房间频道**：只同步给当前 `school:class-N` 里的人。进房拉最近约 80 条，离房听不见新消息。
- 走廊不做黑板，只对走近的人显示头顶气泡（约 5 秒）。
- 学校里谁都能看见谁，不要求先加好友。

### 家（私密）

- 自己随时能回。
- 别人串门必须是好友，且主人同意（敲门）。
- 主人不在家但在线：桌宠冒泡，可一键回家迎接。
- 主人离线：第一刀直接拒绝，不做「空屋常驻」。
- 客厅里的人共用一套附近聊天。

### 点到另一个宠物

同一径向菜单，按关系显示不同项：

- **同学/陌生人**：挥手、加好友、看名片
- **好友**：再加上飞踢、倒水、抱抱、邀请回家、猜拳、五子棋

动作是广播动画，无血条。冷却约 5 秒。陌生同学不能整蛊。

### 小游戏

邀请 → 对方桌宠或世界内确认 → 双方进入 overlay，暂停走动。局内状态机在服务端。结束回原房间。

麻将四人规则重，不进第一刀。

## 为什么必须有服务器

v1 的 EXE 彼此不认识。位置、黑板、好友、邀请、棋谱都要一个房主：

- 协议：WebSocket JSON
- 默认端口：`18765`
- 你的电脑先当房主，同事填 `ws://内网IP:18765`
- 后期再加房间密码；第一刀信任内网

## 技术实现

```
同事 EXE
  ├─ 桌宠窗：枢纽、邀请气泡、LLM
  ├─ 世界窗：场景、WASD、黑板、对局 overlay
  └─ 主进程：窗口 + 本地 pet 档案 + 转发 WS
        │
        └── WebSocket --> bbpet-server（你的电脑）
                          ├─ presence / placeId / x,y
                          ├─ chat 环形缓冲（按房间）
                          ├─ friends 双向同意
                          ├─ visit / game 邀请
                          └─ 猜拳、五子棋状态机
```

- 服务端：Node + `ws`，独立 `bbpet-server`（或 EXE 里「我来当校长」开关，演示用）。
- 客户端场景：16×16 瓷砖 + 现有 `PixelPet` canvas，`imageSmoothing = false`。不引入 Phaser / 3D / WebRTC。
- 身份：本机 UUID + 宠物名，可选带 Windows 登录名。好友存在服务器 JSON，内网几十人够用。
- 同步：坐标 10Hz；聊天、动作、邀请走事件。客户端权威移动，服务端夹紧边界后广播。
- 不要把 LLM Key、天气、新闻、私聊历史传到房主。

### placeId 就是频道

| placeId | 谁在里面 | 同步 |
| --- | --- | --- |
| `school:campus` | 操场上的人 | 坐标 + 近距气泡 |
| `school:class-1` 等 | 走进该班的人 | 坐标 + 黑板历史 |
| `home:{ownerId}` | 主人和获准访客 | 坐标 + 客厅聊天 + 动作 |
| `game:{gameId}` | 本局玩家 | 回合状态，不播坐标 |

### 主要报文

客户端 → 服务端：`hello` `enterPlace` `move` `chat` `emote` `friendRequest` `friendAccept` `visitRequest` `visitAccept` `inviteGame` `gameMove`

服务端 → 客户端：`welcome` `snapshot` `presence` `chat` `invite` `gameState`

## 分期

不要一次做完。四块产品叠上去：

1. **v2.0 社交核**：枢纽 + 身份 + 房主 + 学校 WASD + 四间教室黑板
2. **v2.1 家与好友**：自己的家、双向好友、敲门串门、客厅聊天
3. **v2.2 互动**：飞踢/倒水等动作、桌面邀请气泡、关系权限
4. **v2.3 棋牌**：先猜拳，再五子棋；麻将单独估工期

明确不做：语音、私聊、朋友圈、公网穿透、和 LLM 在黑板里插话、空屋常驻、对陌生人整蛊。

## 部署（仍先本地）

1. 你这台机起 `bbpet-server`（建议脚本 `npm run room`）。
2. 防火墙放行局域网入站 18765。
3. 同事 EXE 设置里填 `ws://192.168.x.x:18765`。
4. 以后换常驻内网机器，只搬房主进程，桌宠安装包不用重做。

## 验收草案（做到哪期验哪期）

**v2.0**

- 左键出现枢纽，LLM 仍能单独打开。
- 三人进学校，能看见彼此走动。
- 两人进同一班级，黑板上 1 秒内看到字；第三人在隔壁班看不到。
- 断线重连出生在门口，不卡墙。

**v2.1**

- 加好友双向同意后可敲门。
- 主人同意后访客出现在客厅，客厅聊天互见。
- 拒绝或超时后访客仍在原处。

**v2.2 / v2.3**

- 飞踢双方都播动画，陌生人菜单里没有这项。
- 猜拳/五子棋邀请可从桌面气泡接，对局结束后回到原房间。
